# 我的工作台（手机版）

一个只给自己用的学习生活工作台：课表、三件要事、DDL 倒计时、习惯打卡、今日复盘。
纯静态页面，手机浏览器打开即用，可以「添加到主屏幕」当 App 使。

## 数据存在哪

- **不会上传到任何服务器。** 所有数据存在你手机的浏览器本地（localStorage）。
- 换手机 / 备份：在「设置 → 数据」里复制导入链接，或导出 JSON 文件。
- 电脑关机、断网都能打开（页面本身带离线缓存）。

## 怎么用

1. 手机浏览器打开链接 → 菜单里选「添加到主屏幕」。
2. 「今日」页：看今天的课、打卡三件要事和习惯、写复盘。
3. 「课表」页：看整周课程，可以按单双周 / 第几周筛选。
4. 「任务」页：加 DDL 和倒计时，改默认的三件要事。
5. 「设置」页：改名字、开学第一周、作息时间，导入导出数据。

## 改课表

「设置 → 数据」里直接改 JSON 再点「应用」。课表格式：

```json
"schedule": {
  "1": [
    { "from": 1, "to": 2, "name": "高等数学（一）上", "teacher": "周丽珍",
      "place": "东教楼 609", "weeks": "2-17" }
  ]
}
```

- `"1"` 到 `"7"` 是周一到周日；`from`/`to` 是第几节。
- `weeks` 是第几周到第几周；单周加 `"odd": true`，双周加 `"even": true`。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构和样式 |
| `app.js` | 全部逻辑 |
| `data.js` | 默认示例数据（不含个人数据） |
| `sw.js` | 离线缓存 |
| `manifest.webmanifest` | 添加到主屏幕用的配置 |
